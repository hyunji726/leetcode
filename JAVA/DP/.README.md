# 💡 DP (Dynamic Programming, 동적 계획법)

### 개념
- 복잡한 문제를 작은 하위 문제로 나누어 해결하는 알고리즘 기법입니다.
- 이미 계산한 하위 문제의 정답을 메모리(배열 등)에 저장해 두고 재사용하여 중복 계산을 피합니다.

### 핵심 키워드
- **메모이제이션(Memoization) / DP 테이블**: 이전 계산 결과를 저장하는 공간
- **점화식**: 작은 문제와 큰 문제 사이의 관계식 (예: `dp[i] = dp[i-1] + dp[i-2]`)

### 접근 방법
1. 구하려는 값이 무엇인지 정의하기 (`dp[i]`의 의미)
2. 점화식(관계식) 세우기
3. 초기값(기초 문제의 답) 설정하기
4. 반복문(Bottom-Up) 또는 재귀(Top-Down)로 해결하기
