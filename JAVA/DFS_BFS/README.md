# 🔍 DFS / BFS (깊이/너비 우선 탐색)

### 개념
- **DFS (Depth-First Search, 깊이 우선 탐색)**: 한 노드에서 시작해 다음 가지로 넘어가기 전, 해당 가지를 끝까지 깊게 탐색하는 방식입니다.
- **BFS (Breadth-First Search, 너비 우선 탐색)**: 시작 노드에서 가까운 노드부터 우선적으로 넓게 탐색하는 방식입니다.

### 핵심 차이점 및 자료구조
| 구분 | DFS | BFS |
| :--- | :--- | :--- |
| **탐색 방식** | 깊게 파고들기 | 가깝고 넓게 탐색하기 |
| **주요 자료구조** | 재귀 함수(Recursion) 또는 스택(Stack) | 큐(Queue) |
| **주요 활용** | 모든 경로 탐색, 백트래킹, 미로 찾기 | 최단 거리 / 최단 경로 찾기 |

### 접근 방법
1. **방문 처리 (`visited` 배열)**: 이미 방문한 노드를 재방문하여 무한 루프에 빠지지 않도록 설정합니다.
2. **DFS 구현**: 재귀 호출(또는 스택)을 이용해 한 방향으로 계속 이동합니다.
3. **BFS 구현**: `Queue`에 시작 노드를 넣고, 큐가 비어있지 않을 때까지 반복문(`while`)을 돌아 탐색합니다.
