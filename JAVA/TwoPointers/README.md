# 👈👉 Two Pointers (투 포인터)

### 개념
- 배열이나 리스트에서 **두 개의 지점(인덱스/포인터)**을 가리키며, 조건에 따라 두 포인터의 위치를 이동시키면서 문제를 해결하는 기법입니다.
- 보통 이중 반복문($O(N^2)$)으로 풀어야 하는 문제를 **$O(N)$**의 선형 시간에 해결할 수 있게 해줍니다.

### 주요 유형
1. **양끝에서 시작하는 포인터** (`left = 0`, `right = N - 1`)
   - 보통 **정렬된 배열**에서 "두 수의 합이 K가 되는 쌍 찾기" 등에 사용
2. **같은 방향에서 시작하는 포인터** (`left = 0`, `right = 0`)
   - "연속된 부분 배열의 합이 K 이상인 최소 길이 구하기" 등에 사용

### 접근 방법
1. 배열을 정렬하거나(필요한 경우) 두 포인터의 초기 위치 설정 (`left`, `right`)
2. `left`와 `right`가 가리키는 값의 조건 검사
3. 조건에 맞게 포인터 이동 (`left++` 또는 `right--`)
4. 두 포인터가 만날 때까지 반복
